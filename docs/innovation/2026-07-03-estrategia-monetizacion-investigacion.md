## Resumen ejecutivo

AGIGOV tiene **infraestructura técnica avanzada** (ledger, agentes, bus IAP, PWA) pero **brecha de legitimidad y producto económico visible**. Monetizar antes de cerrar MVP institucional (Carta + proyectos DAO trazables) destruye credibilidad.

**Verdad operativa hoy:** el protocolo vende **confianza verificable** (presupuesto, proyectos, participación), no «otra criptomoneda».

**Recomendación central:** ejecutar **90 días de legitimidad + prosperidad visible** (brief `2026-07-02-agigov-mvp-brief.md`) y **en paralelo** diseñar **3 vectores de ingreso** sin emitir token de gobernanza nacional hasta dictamen soberano.

## 2. Cómo funciona el protocolo (síntesis para negocio)

```
Carta (reglas) → Agentes (decisión) → Ledger (prueba) → PWA (transparencia)
                      ↑
              Bus IAP + nodos edge (offline-first)
```

| Capa | Qué vende al cliente | Estado repo |
|------|----------------------|-------------|
| Evidencia firmada | «Nadie cambia el acta sin firma» | Operativo |
| Escrow programático | «El dinero se libera con hito» | Backend; UI parcial |
| Telemetría pública | «El ciudadano ve gestión real» | `/gestion` demo |
| Multi-sig / PQC | «Resistente a fraude y quantum» | PQC doc; piloto pendiente |

**Brecha crítica:** participación (`/participar`) y economía visible (`/proyectos` + aportes) — sin esto el protocolo no se **monetiza** con gobiernos serios.
