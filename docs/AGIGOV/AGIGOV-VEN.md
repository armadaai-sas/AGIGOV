# AGIGOV-VEN — Modelo para Venezuela

Implementación nacional del protocolo **AGIGOV** para la República Bolivariana de Venezuela.

## Identidad

| Campo | Valor |
|-------|-------|
| Código | `AGIGOV-VEN` |
| Jurisdicción | Venezuela |
| Nodo estratégico demo | `BOG_CENTER_01` / `MAR_NORTH_01` |
| Idioma oficial UI | Español (es-VE) |
| Moneda referencia | VES + token gobernanza (ver ECONOMIA-DAO.md) |

## Objetivo nacional

Reconstruir confianza institucional mediante:

1. **Transparencia radical** — gestión visible sin datos personales expuestos
2. **Participación verificable** — voto y propuestas con trazabilidad
3. **Economía para todos** — proyectos, escrow, DAO de prosperidad
4. **Soberanía territorial** — nodos en estados/municipios con sync offline
5. **Seguridad adversarial** — PQC, centinela 24/7, respuesta a fraude

## Estructura institucional (mapeo agentes)

| Institución conceptual | Agente AGIGOV | Función |
|------------------------|---------------|---------|
| Contraloría / Auditoría | **centinela** | Integridad ledger, FREEZE |
| Planificación / Recursos | **logistico** | Suministros, escrow, rutas |
| Gobernanza / Legal | **soberano** | Carta, dictámenes, lenguaje ciudadano |
| Justicia / Mediación | **conciliador** | Disputas, grafo de confianza |
| Transparencia / Prensa digital | **comunicador** | Dashboards, telemetría pública |

## Carta AGIGOV-VEN (borrador — principios)

1. **Soberanía del ciudadano verificable** — identidad DID, voto no repudiable
2. **Estado transparente por defecto** — lo no publicado no es gestión oficial
3. **Economía programática** — fondos liberados por hitos auditables
4. **Equidad territorial** — nodos periféricos con mismos derechos que capital
5. **Humanismo digital** — tecnología al servicio de la dignidad, no al revés
6. **Puente internacional** — compatible con red AGIGOV global sin ceder soberanía local

## Relación con política tradicional

AGIGOV-VEN **no sustituye** de un día para otro las instituciones existentes. Propone:

- **Puente:** actas y ledger como evidencia paralela verificable
- **Presión positiva:** transparencia que obliga a la política tradicional a responder con datos
- **Transición:** pilotos → ratificación → ampliación legal (ver POLITICA-2.0.md)

## Ratificación requerida

Antes de declarar AGIGOV-VEN «oficial», se requiere:

- [ ] Acta multi-sig con ≥3 DIDs institucionales
- [ ] Auditoría centinela sin discrepancias
- [ ] Informe comunicador publicado en PWA
- [ ] Human-in-the-loop: firmantes humanos identificados fuera del ledger
