# Gestión B2G — FAQ objeciones

Material complementario a [gestion-b2g.md](../one-pagers/gestion-b2g.md).

## Para contraloría

**¿Puedo auditar sin AGIGOV?**  
Sí — exportar hashes de reportes y ledger entries; recuento reproducible desde evidencia publicada.

**¿Qué entra al dashboard ciudadano?**  
Solo estado **published** — actos en validación o con FREEZE no aparecen como gestión cerrada.

## Para el ministro / secretaría

**¿Sustituye informes legales?**  
**No** — complementa con telemetría continua; informes formales siguen su marco legal.

**¿Riesgo político?**  
Piloto acotado; ciudadano ve agregados, no expedientes personales ni datos sensibles de seguridad.

## Para TI / operaciones

**¿Integración con sistemas legacy?**  
Roadmap — hoy demo vía agentes y API pública; ingest documentado en Fase 3–5.

**¿Offline?**  
Nodos territoriales sync al reconectar; dashboard central refleja **published** tras commit.

## Lo que no prometemos

- Sustituir contraloría formal
- Publicar PII o datos clasificados
- Escala nacional sin acta multi-sig
