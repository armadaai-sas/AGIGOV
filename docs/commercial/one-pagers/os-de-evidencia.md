## En una frase

No somos «otro ERP ni otra consultora». Somos el **sistema operativo de evidencia**: protocolo + runtime que hace que **gasto, hito y publicación** compartan **una sola prueba** — y se **congelen** si no cuadran.

## Problema que resolvemos

Cada oficina tiene **su versión** del número. El ciudadano ve PDFs. El auditor llega **meses después**. El contratista cobra por presión, no por hito. Cuando hay discrepancia, el sistema **sigue** — y el daño crece.

**Con AGIGOV:** discrepancia → **FREEZE** → humano decide → recién entonces `committed` / `published`.
